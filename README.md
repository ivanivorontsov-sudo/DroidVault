# DroidVault

**DroidVault** — резервное копирование и перенос Android-приложений через ADB.

> Текущий этап: ранний CLI-прототип. Это не «полный клон телефона»: Android намеренно закрывает приватные данные чужих приложений от обычных приложений и ADB без специальных привилегий.

## Что умеет текущий прототип

- обнаруживать подключённые устройства через ADB;
- показывать установленные сторонние пакеты;
- извлекать APK каждого пакета, включая split APK;
- сохранять метаданные и SHA-256 каждого APK в manifest.json;
- проверять целостность уже созданной копии;
- устанавливать APK-набор на подключённое устройство.

## Чего пока НЕ умеет

- копировать приватные каталоги приложений, базы данных и внутренние настройки;
- переносить учётные записи, пароли, токены, данные Android Keystore или аппаратно привязанные ключи;
- гарантировать совместимость приложения между разными версиями Android и устройствами;
- обходить ограничения производителя, Play Integrity, DRM или системные политики.

Для доступа к приватным данным другого приложения обычно нужны root/системные привилегии либо штатный механизм резервного копирования самого приложения. Root-восстановление будет отдельным экспериментальным режимом и не входит в этот MVP.

## Требования

- Python 3.10+
- Android Platform Tools (adb) в PATH
- USB debugging включён на телефоне и компьютер авторизован
- Windows, Linux или macOS

Проверить ADB:

~~~bash
adb version
adb devices
~~~

## Установка из исходников

~~~bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -e .
~~~

## Использование

~~~bash
droidvault devices
droidvault list
droidvault backup com.example.app --output ./vault
droidvault verify ./vault/com.example.app
droidvault restore ./vault/com.example.app
~~~

Можно указать серийный номер устройства через --serial для команд, работающих с телефоном.

Резервная копия создаётся в отдельной папке пакета. Для split-приложений сохраняются все APK, возвращённые Android командой pm path. Восстановление использует adb install-multiple -r.

## Формат копии

~~~text
vault/
  com.example.app/
    manifest.json
    base.apk
    split_01.apk
~~~

В манифесте хранятся package name, версия (если её удалось извлечь), дата копирования, сведения об устройстве и SHA-256 каждого APK.

## Безопасность

- Не подключайте чужое или недоверенное устройство.
- Не публикуйте резервные копии: APK могут быть проприетарными, а будущие версии формата могут содержать пользовательские данные.
- Не храните пароли и ключи в командной строке или Git.
- Проверяйте хеши перед восстановлением.
- Восстановление APK не равно восстановлению данных приложения.
